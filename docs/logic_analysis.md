# SimBaseBall-game 成績計算ロジック仕様書

## 1. 概要
本ドキュメントでは、SimBaseBall-gameにおける試合シミュレーションの核となる、選手能力に基づいた成績確率の計算ロジック（`src/services/formulaCalculations.ts`）の仕様を記述します。
現在のロジックは、**「打者有利（防御率1点台過多の防止）」**と**「三振が取れる（球威がある）投手の優位性」**の両立を目指して調整されています。

## 2. 確率計算フロー

1打席ごとの結果確率は、以下の手順で算出されます。

1.  **基本打率（Hit Probability）**の算出
2.  **安打内訳（HR、2塁打、3塁打、単打）**の比率配分
3.  **四球・三振**の確率算出
4.  **凡打（Out）**の確率算出と、**インプレー打球のヒット化（運要素）**の加味

## 3. 詳細計算ロジック

### 3.1. 打率 (Hit Probability)

投打の基本能力から算出される、打席がヒットになる基本確率です。

*   **基準打率**: `.255`
    *   *調整意図*: 全体的な打率を底上げし、極端な投高打低を防ぐ。
*   **打者能力補正**: `(Contact - 10) * 0.010`
    *   Contact 1につき打率1分上昇。
*   **投手能力補正**: `(Control - 10) * -0.005`
    *   Controlが良いほど打率は下がるが、影響力は小さめに設定（四球への影響を主とするため）。
*   **球速（球威）補正**: `(PitcherSpeed - 145) * -0.001`
    *   145km/hを基準に、速くなるほど被安打率が下がる。155km/hで-1%。
*   **変化球補正**:
    *   持ち球のゴロ率（Ground）に応じて被安打率を減少させる。

$$ HitProb = 0.255 + BatterModifier + PitcherModifier + SpeedModifier $$
*（上限 .450 / 下限 .100）*

### 3.2. 安打内訳 (Hit Breakdown)

ヒットが出た場合、それがどの種類のヒットになるかを決定します。

1.  **ホームラン率 (vs Hit)**
    *   **計算式**: `HitProb * HRRatio`
    *   **HR比率**: `0.10 + (Power - 10) * 0.03`
    *   **弾道補正 (Trajectory)**:
        *   弾道3以上: `+0.05` 〜 `+0.10` （フライヒッターはHRが多い）
        *   弾道1: `-0.05` （ゴロヒッターはHRが少ない）
    *   **球速補正 (被弾抑制)**: `(PitcherSpeed - 140) * 0.002` 分だけ減少。速球派ほどHRを打たれにくい。

2.  **長打率 (2B, 3B)**
    *   **3塁打率**: `HitProb * (0.02 + (Speed - 10) * 0.005)`
    *   **2塁打率**: `HitProb * (0.20 + (Speed - 10) * 0.01 + Power影響)`
        *   弾道3以上: `+0.05`、弾道1: `-0.05` の補正あり。

3.  **単打率**
    *   `HitProb - (HR + 3B + 2B)`
    *   **弾道1補正**: ゴロヒッター（弾道1）の場合、計算後の単打率を **1.1倍** して内野安打やゴロ安打の多さを表現。

### 3.3. 四死球・三振

1.  **四球率 (Walk Probability)**
    *   **基準値**: `.080`
    *   **補正**:
        *   打者 Eye（選球眼）: `+`
        *   打者 Aggressiveness（積極性）: `-`
        *   投手 Control: `-`

2.  **三振率 (Strikeout Probability)**
    *   **基準値**: `.190`
    *   **球速補正**: `(PitcherSpeed - 146) * 0.009`
        *   146km/h基準。+10km/hで約9%上昇。最も影響力が大きい。
    *   **他補正**:
        *   打者 Contact: `-`
        *   変化球（Whiff）: `+`
        *   選球眼・積極性: `-`

### 3.4. 凡打のヒット化（インプレー打球リスク）

アウトになるはずの打球が、運や守備、球威不足によってヒットになってしまう確率です。**ここが投手評価の調整弁となっています。**

*   **計算式**: `ReducedOut = NormalOut * ReductionFactor`
*   **減少分（ヒット化分）**: `NormalOut - ReducedOut` を単打（Single）に加算。

**ReductionFactor（アウト維持率）の決定:**
投手の球速による線形補間を行います。

| 球速 | 係数 (Factor) | 意味 |
| :--- | :--- | :--- |
| **130km/h 以下** | **0.88** | 凡打の **12%** がヒットになる（被BABIPが高い、防御率悪化） |
| **〜 (線形補間) 〜** | | 球速が上がるほどリスク減少 |
| **158km/h 以上** | **0.96** | 凡打の **4%** がヒットになる（被BABIPが低い、防御率良化） |

#### 調整のポイント
*   **打者有利**: 最速の投手でも `0.96` とすることで、完全には抑えきれない（4%はヒットになる）ようにし、防御率1点台が頻発するのを防いでいます。
*   **三振投手の優位性**:
    1.  三振自体が「インプレーにならない」ため、このヒット化リスクを回避できる唯一の手段です。
    2.  球速がある投手は三振が取りやすく、かつインプレーになっても係数が高い（0.96）ため、二重に守られています。

## 4. パラメータ一覧

| パラメータ | 設定値 | 備考 |
| :--- | :--- | :--- |
| `baseAvg` | **0.255** | 全体打率のベースライン |
| `baseKRate` | **0.190** | 三振率のベースライン |
| `baseWalkRate` | **0.080** | 四球率のベースライン |
| `minSpeedLimit` | 130.0 | ヒット化リスク最大の下限球速 |
| `maxSpeedLimit` | 158.0 | ヒット化リスク最小の上限球速 |
| `minReduction` | 0.88 | 最大リスク係数（軟投派） |
| `maxReduction` | 0.96 | 最小リスク係数（速球派） |
